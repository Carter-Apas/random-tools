How the point model works

Each enabled curve turns one input into signed points. We add the earned points, divide by the sum of every enabled curve’s maximum, then multiply by 100 and clamp the result to 0–100. A curve with a larger positive maximum has more influence. Negative points cancel positive ones; a large negative penalty can make the whole day a zero.

Smooth curves stay inside their control-point values, so the displayed maximum is the true maximum. Linear and step functions are also available. Outside a curve’s control-point range, its endpoint value is held. Direction curves wrap at north. Disabled variables are ignored, including their maxima. An enabled curve with missing input makes the score unavailable.
